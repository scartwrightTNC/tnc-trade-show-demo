# Trade Show Demo Screen

Interactive demo application for trade show booths showcasing TNC's feature offerings.

**Live Demo:** https://tnc-trade-show-demo.vercel.app

## Features

- Responsive design for touch screens, mobile, and desktop
- Attraction screen mode with animated content
- Offline capability via service worker
- Vercel Analytics integration
- QR code generation for easy access

## Demo Categories

### Enterprise
- Store Audit / Field Tools
- Maintenance Management
- Budgets
- Contracts

### Customer XP
- MyQiosk
- MyQiosk Live
- Access+

### Standalone Services
- Revenue Pro
- NOAWEB

### Management Services
- Full Service
- Remote Management
- NOA+ Self Management

## Deployment

Deploy to Vercel:

```bash
vercel --prod
```

Or connect GitHub repository for automatic deployments.

## Local Development

Serve locally:

```bash
npx serve .
```

## Analytics

View analytics in the Vercel dashboard under the Analytics tab.
